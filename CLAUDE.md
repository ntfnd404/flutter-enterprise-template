# CLAUDE.md

Use [AGENTS.md](AGENTS.md) for contributor instructions,
[application architecture](doc/architecture.md) for startup and ownership
contracts, and [code style](doc/code_style.md) for implementation conventions.

The architecture document is the normative target. The
[roadmap](doc/roadmap.md) records accepted commits, ordered review patches, and
temporary gaps; it cannot override architecture. The Context Map contains only
DDD topology already accepted in Git.

The package is named `template`. Do not import architecture or domain rules
from external reference applications without an explicit, independently
reviewed migration decision.
